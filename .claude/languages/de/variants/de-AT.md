# de-AT overlay

Overlay for Austrian German on the `de` pack (spec §4.5). Wins over the base
files wherever they differ; option values in force win over this file.

Austrian Standard German is a standard variety, not a dialect: Austrian forms
are correct, never errors. Do not "correct" them towards German usage.

## Authority

*Österreichisches Wörterbuch* (ÖWB), the official reference for schools and
administration in Austria, which follows the same official rules. Duden for
questions the ÖWB does not settle (Duden marks Austrian forms *österr.*).

## Spelling and grammar

- Same orthography and ß/ss rules as the base pack.
- **Perfect auxiliary:** *sein* with *sitzen, stehen, liegen, hängen*
  (*ich bin gesessen*): standard here.
- **Gender of some nouns:** *das Cola*, *das E-Mail* (both genders allowed),
  *der Gehalt* (also *das*), *das Monat* is regional — follow the author.
- **Plurals and endings:** *die Pölster* (also *Polster*), *Krägen*.
- Linking *-s-* in compounds where German has none: *Zugsverkehr*,
  *Schweinsbraten*, *Gesangsverein*; and none where German has one:
  *Adventkalender*, *Fabrikarbeiter*.

## Vocabulary (Austriazismen)

Correct Austrian forms, to be kept in the author's text and used in
Claude-drafted text where the setting or register calls for them:

| de-AT | de-DE |
|---|---|
| *Jänner* | *Januar* (*Feber* for *Februar* is rarer, mainly spoken) |
| *heuer* | *dieses Jahr* |
| *Matura*, *maturieren* | *Abitur* |
| *Paradeiser*, *Erdäpfel*, *Karfiol*, *Topfen* | *Tomaten*, *Kartoffeln*, *Blumenkohl*, *Quark* |
| *Sessel* | *Stuhl* |
| *Kasten* | *Schrank* |
| *Spital* | *Krankenhaus* |
| *Stiege* | *Treppe* |
| *Trafik* | *Kiosk* (tobacconist) |
| *Obers*, *Schlagobers* | *Sahne* |

## Dates and typography

- *9. Jänner 2026*.
- Quotation marks as in the base pack (*„…“*, or »…« in books).

## Academic

- Universities follow the same conventions as in the base pack; titles and
  degree names are Austrian (*Diplomarbeit*, *Masterarbeit*, *Dissertation*;
  *Mag.*, *Dr.*). Legal citations follow Austrian practice (e.g. *§ 1295
  ABGB*), which the brief usually specifies.
