# de-DE overlay

Overlay for German as used in Germany on the `de` pack (spec §4.5). Wins over
the base files wherever they differ; option values in force win over this
file.

The base pack describes German-standard usage, so this overlay adds little:

- **Authority:** *Duden – Die deutsche Rechtschreibung* as the reference
  dictionary for the official rules.
- **Quotation marks:** „…“ and ‚…‘; »…« in book typesetting.
- **Months:** *Januar*, *Februar*.
- **Perfect auxiliary:** *haben* with *sitzen, stehen, liegen* (*ich habe
  gesessen*); *sein* is southern German and Austrian: in narration flag it
  unless it is voice.
- **Vocabulary:** prefer common German forms in Claude-drafted text
  (*Kartoffel*, *Tomate*, *Abitur*, *Krankenhaus*); regional words in the
  author's text are voice, not errors.
